由比滨结衣 Live2D Windows 版使用指南
================================================

一、快速启动

1. 如果收到的是压缩包，请先将整个压缩包解压到普通文件夹。
2. 双击“启动结衣Live2D.cmd”。
3. 稍等几秒，系统会自动用默认浏览器打开展示页。
4. 使用期间请保持黑色启动窗口开启；关闭该窗口即可停止运行。

不需要安装 Live2D、Node.js 或其他开发软件，也不需要联网。


二、页面功能

· 移动鼠标：结衣的视线会跟随指针。
· 服装：可切换制服和私服。
· 互动演示：可开关模拟说话与目光跟随。
· 表情和动作：点击名称即可切换或播放，部分效果再点一次可关闭。


三、电脑要求

· Windows 10 或 Windows 11。
· 建议使用 Microsoft Edge 或 Chrome。
· 显卡需支持 WebGL（近年的 Windows 电脑通常默认支持）。


四、常见问题

1. 浏览器没有自动打开
   保持启动窗口开启，将窗口中的 http://127.0.0.1:端口号/ 复制到浏览器地址栏。

2. Windows 弹出安全提示
   确认文件来源可信后，可点击“更多信息”并继续运行。

3. 页面打开但人物没有出现
   按 Ctrl + F5 强制刷新。如果仍无效，请换用 Edge 或 Chrome，并更新显卡驱动。

4. 提示文件不完整
   请不要单独移动启动文件，必须保留“程序文件”和“网页文件”两个文件夹。


五、隐私与使用说明

本程序只在本机 127.0.0.1 上运行，不会向外网上传模型或使用数据。
模型资源仅用于个人研究与本地预览，请勿未经授权公开发布或商业使用。
