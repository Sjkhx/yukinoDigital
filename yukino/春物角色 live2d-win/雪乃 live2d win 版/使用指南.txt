雪之下雪乃 Live2D Windows 版使用指南
================================================

一、最快使用方法

1. 如果收到的是压缩包，请先将整个压缩包解压到普通文件夹。
2. 双击“启动雪乃Live2D.cmd”。
3. 稍等几秒，系统会自动用默认浏览器打开展示页。
4. 使用期间请保持黑色启动窗口开启。关闭该窗口后，网页将停止运行。

不需要安装 Live2D、Node.js 或其他开发软件，也不需要联网。


二、页面怎么玩

· 移动鼠标：雪乃的视线会跟随指针。
· 服装：可切换“制服”和“私服”。
· 模拟说话：展示说话时的口型动画。
· 目光跟随：可随时开启或关闭。
· 表情：点击表情名称即可切换。
· 动作：点击动作名称即可播放。某些效果再点一次可关闭。


三、电脑要求

· Windows 10 或 Windows 11。
· 建议使用系统自带的 Microsoft Edge，也可使用 Chrome。
· 显卡需支持 WebGL（近年的 Windows 电脑通常默认支持）。


四、常见问题

1. 双击后浏览器没有自动打开
   请不要关闭黑色启动窗口，将窗口里显示的 http://127.0.0.1:端口号/ 复制到浏览器地址栏。

2. Windows 弹出安全提示
   请确认文件来源可信。如果是 Windows 保护提示，可点击“更多信息”后选择继续运行。

3. 页面打开但人物没有出现
   按 Ctrl + F5 强制刷新。如果仍然无效，请换用 Edge 或 Chrome，并更新显卡驱动。

4. 提示“程序文件不完整”
   请不要单独移动启动文件；必须保留“程序文件”和“网页文件”两个文件夹。建议重新完整解压。

5. 想要退出
   关闭黑色启动窗口，再关闭浏览器页签即可。
