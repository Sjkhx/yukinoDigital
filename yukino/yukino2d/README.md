# Yukino2D — Live2D 风格模型（网页版）

基于 `ref.png` 立绘构建的 **Live2D 风格** 交互模型：用 WebGL 网格变形实现
**嘴部开合（含牙齿/口腔纹理）、自动眨眼**（头部跟随、呼吸、发丝摆动已停用），
并支持 **麦克风实时口型同步**。纯单文件 HTML，双击即可运行，无需安装任何东西。

> 说明：本模型为 Live2D *风格* 的网页实现（自研 WebGL 网格变形引擎），
> 并非 Live2D Cubism 的 .moc3 格式。优点是完全开源可控、无需授权。

## 运行

**直接双击 `index.html`** 即可（推荐 Chrome / Edge）。

- 打开后角色自动进入「自动说话」模式：嘴巴随语音节奏自然开合，眼睛随机眨眼
- 点击「🎤 麦克风」：对着麦克风说话，口型实时同步（需浏览器授权麦克风）
- 除嘴部与眼睛外，角色整体静止（头部/呼吸/发丝摆动已去除）

### 麦克风不工作？

- 部分浏览器对 `file://` 协议的麦克风有安全限制，可用本地服务器：
  ```bash
  cd 本项目目录
  python -m http.server 8000
  # 然后浏览器打开 http://localhost:8000
  ```
- 或直接改用「自动说话」模式（默认已开启）。

## 操作

| 控件 | 功能 |
|---|---|
| 嘴部 自动说话/麦克风/手动 | 口型模式切换（手动可拖「张开度」滑块） |
| 眼睛 自动眨眼/手动 | 眨眼模式（手动可拖「睁开度」滑块） |
| 👁 眨眼 | 立即眨一次眼 |
| 🔧 调试 | 显示/隐藏特征点网格（快捷键 `D`） |
| 快捷键 | `D` 调试 · `B` 眨眼 · `M` 麦克风 · `T` 切换自动说话 |

## 预览参数（URL）

`index.html?mouth=0.8&blink=1&dbg=1&t=1` —— 单帧预览模式，便于调参/截图：

| 参数 | 含义 |
|---|---|
| `?t=秒数` | 以指定时间渲染单帧（供测试） |
| `?mouth=0~1` | 嘴部张开度 |
| `?eye=0~1` | 眼睛睁开度（0=闭眼） |
| `?blink=1` | 强制闭眼 |
| `?dbg=1` | 显示调试网格与特征框 |
| `?dump=1` | 将当前帧以 base64 PNG 输出到页面（供程序化抓帧） |

## 自定义 / 换图

所有特征坐标与幅度集中在 `index.html` 顶部的 `CONFIG` 中（含中文注释）：

```js
const CONFIG = {
  img: 'ref.png',
  size: { w: 1279, h: 2177 },
  grid: 12,                          // 网格精度
  face:   { cx: 696, cy: 793, ... }, // 脸中心/大小
  eyeL:   { cx: 605, cy: 722, ... }, // 左眼
  eyeR:   { cx: 784, cy: 716, ... }, // 右眼
  mouth:  { cx: 700, cy: 810, ... }, // 嘴
  browY:  690, neckY: 905,           // 眉线 / 颈线
  amp: { headTurn: 14, jawDrop: 43, ... },  // 动画幅度
};
```

换新立绘时：

1. 运行 `python tools/detect_features.py 新图.png tools/features.json`
   —— 自动检测脸/眼/嘴坐标，并生成带标注的 `features_out.png` 供核对；
2. 将 JSON 结果填入 `CONFIG`；
3. 打开页面按 `D` 键微调坐标（调试视图实时显示特征框）。

## 技术原理

- **网格变形**：立绘按 12px 网格三角化（约 2 万顶点），每顶点预计算各
  变形特征（嘴/眼）的权重；每帧仅做线性加权，性能开销极小。
  头部跟随/呼吸/发丝摆动权重已置零（`CONFIG.amp`），角色静止。
- **嘴部**：下唇以下顶点按高斯衰减向下位移形成「下巴下沉」，上唇保持静止，
  上下唇之间露出预绘制的**口腔纹理**（深色口腔渐变，无舌头），张度由参数驱动。
- **眨眼**：眼内顶点向闭合线压缩（上睑下压、下睑上收），虹膜自然消失。
- **口型同步**：Web Audio API 分析麦克风音量（RMS），驱动嘴部开合；
  无麦克风时用音节包络模拟说话节奏。
- 渲染：WebGL 单着色器绘制，纹理双线性采样；全分辨率 1279×2177 输出。
