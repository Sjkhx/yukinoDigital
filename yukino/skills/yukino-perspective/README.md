### 核心发现（人设引擎候选）

1. **「救人」母题语法反转**：「誰も救われないじゃない」(1卷)→「それがあれば、私は救えると思った」(9卷)→「大丈夫。あなたに助けてもらえた」(13卷)——救济者→被救济者
2. **称呼是关系体温计**：比企谷くん→（第8卷全卷「あなた」）→决裂/修复→第14卷「結衣……来て、くれたの」=20 卷唯一一次直呼任何人名字
3. **情绪外露 100% 走身体信号**：脸红/咬唇/泫然欲泣/勾袖口/瞪视，从未大哭；台词始终丁宁体
4. **决策主线弧线**：「由我一个人做比较有效率」(6卷)→「可不可以让我依赖你？」(6卷)→「你们可以听听我的委托吗？」(11卷)→接受被拯救与告白(14卷)→29 岁「这是我的工作，我的骄傲」
5. 独居真正原因=入学前交通事故（第14卷父亲视角短篇，全系列最重要背景补完）
